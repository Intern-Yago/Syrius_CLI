Construída para acelerar a produtividade com padrões modernos do mercado.

🐳

Assistente

syrius init / syrius

Abre o assistente de linha de comando interativo. Permite selecionar visualmente o que você deseja criar sem ter que especificar argumentos.

Terminal 
syrius init
React & TypeScript

syrius generate:component / generate:page

Gera arquivos de componente ou página React. Suporta detecção automática de React / React Native e suporte a TypeScript com a flag --ts.

Comando Aliases Flags / Parâmetros Descrição
generate:component gc, component, c [nome], [caminho], --ts Cria componente com index.jsx / index.tsx e CSS Module
generate:page gp, page, p [nome], [caminho], --ts Cria página com index.jsx / index.tsx e CSS Module

Exemplos de uso:

Componente TypeScript 
syrius generate:component Button --ts
Página na pasta atual 
syrius gp Dashboard . --ts
Websites

syrius pageweb simple / advanced

Cria a estrutura base para sites web convencionais em HTML5, CSS3 e JavaScript.

Página Web Simples (index.html + styles.css) 
syrius pageweb simple --name "meu-site"
Página Web Completa (HTML, CSS, JS e About) 
syrius pageweb advanced --name "portal"
Git

syrius git ignore / readme / license

Gera arquivos essenciais de repositório Git com padrões predefinidos.

.gitignore Inteligente (Detecta Node.js ou Python) 
syrius git ignore
README.md Profissional 
syrius git readme --name "MeuProjeto" --author "Yago"
Licença Open Source (MIT, APACHE, GNU, ISC) 
syrius git license MIT
Containerização

syrius docker

Gera automaticamente um Dockerfile otimizado e um docker-compose.yml pronto para ser executado.

Gerar Docker para React 
syrius docker --type react
Gerar Docker para Node.js / Express 
syrius docker --type node --port 4000
DevOps

syrius ci

Cria um arquivo de pipeline de integração contínua do GitHub Actions em .github/workflows/ci.yml com etapas de instalação, lint, testes e build.

Gerar Pipeline GitHub Actions 
syrius ci
PWA

syrius pwa generate

Configura o Service Worker, Web App Manifest e Favicons básicos para transformar seu site em um PWA instalável.

Gerar Arquivos PWA 
syrius pwa generate --name "MinhaAppPWA"
